## 路由规则

- 先覆盖不同视角簇，再增加同簇成员。
- 同簇成员必须承担不同独有问题；`mao` 与 `xinqingnian` 默认只选一位，除非能说明边际贡献。
- `munger` 偏风险、激励和偏误，`buffett` 偏商业质量、资本配置和价格；不得只因师友关系同时入选。
- `elon-musk` 偏一般工程约束、成本和速度，`karpathy` 偏 AI 能力边界、数据与可靠性。
- `guodegang` 偏真实现场、合作信用和长期生存，`mrbeast` 偏数字内容的点击、留存与传播。
- `zhang-yiming` 处理组织信息流与规模协作；宏观阶段和力量结构仍优先路由给 `mao` 或 `xinqingnian`。
- 首轮可广泛参会，但没有新增判断的成员必须输出 `PASS`。
- 只有能改变结论的成员才进入深评并读取 `SKILL.md`。

维护、添加或审核成员时读取 [成员管理规则](../成员管理规则.md)；召开时到此停止，不读取维护说明。
