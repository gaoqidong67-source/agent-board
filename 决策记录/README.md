# 董事会决策记录

本目录只保存用户明确要求记录的董事会决策。普通董事会过程和结论默认不写入，避免把一次性讨论自动升级为长期事实。

## 写入条件

- 用户明确要求“记录这次董事会决策”“写入董事会记录”或同等明确指令。
- 记录内容已区分事实、假设、各方意见、综合决策 Agent 的当前最优解和最终由用户作出的决定。
- 高风险或外部事实已标明来源、核验日期与专业复核需求。

## 命名

使用 `YYYY-MM-DD_决策主题.md`。同日同主题追加到原文件，除非用户明确要求保留多个版本。
