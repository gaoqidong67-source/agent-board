# 董事会蒸馏来源

本目录保存成员人格 Skills 的共同蒸馏框架或其它来源工具，仅用于追溯和维护，不是董事会成员，也不是普通任务可触发的 Skill。

按用户提供的来源关系，本次导入的 7 位人格成员均由女娲 Skill 蒸馏；该关系作为共同来源记录，不改变各成员原仓库的独立作者、许可证和固定提交。

## 读取边界

- 普通任务和董事会决策均不默认读取本目录。
- 只有维护、审查、更新成员来源，或需要核验蒸馏方法时才按需读取。
- 不执行来源原包中的脚本、安装、联网、生成或写入流程。
